## Описание
Консольная программа вводит массив целых чисел размером от 1 до 100 и выводит:
- исходный массив;
- минимальный и максимальный элементы и их первые индексы (индексация с нуля);
- сумму и среднее арифметическое;
- количество положительных, отрицательных и нулевых элементов;
- количество чётных и нечётных элементов;
- элементы, попадающие в диапазон `[a, b]`;
- результат проверки массива на симметричность.

Массив симметричный, если для каждого `i` выполняется `array[i] == array[size - 1 - i]`.

## Компиляция и запуск
```bash
gcc main.c -Wall -Wextra -Wpedantic -std=c11 -o homework1
```
Windows:
```powershell
.\homework1.exe
```
Linux/macOS:
```bash
./homework1
```

## Входные данные
Сначала вводится размер массива `n` (1–100), затем `n` целых чисел. После статистики вводятся две целые границы `a` и `b`, причём `a <= b`.

## Функции
- `inputArray` — ввод элементов с проверкой;
- `printArray` — вывод массива;
- `findMin`, `findMinIndex` — минимум и его первый индекс;
- `findMax`, `findMaxIndex` — максимум и его первый индекс;
- `calculateSum`, `calculateAverage` — сумма и среднее;
- `printSignsCount` — подсчёт положительных, отрицательных и нулей;
- `printParityCount` — подсчёт чётных и нечётных;
- `printRangeElements` — вывод элементов из диапазона;
- `isSymmetric` — проверка симметричности;
- `performIndividualTask` — вывод результата индивидуального задания.
